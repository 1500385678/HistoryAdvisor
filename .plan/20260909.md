### 1. `backend/main.py` —— FastAPI 最小入口 + 3 路由
- `/` 重定向到 `index.html`(纯静态占位)
- `/person/{id}` 人物页最小版本:SQLite 只读 `data/history.db.figures` 表查 `id = ?`,返回 `name` / `role` / `dynasty` 3 字段(join `dynasties` 表拿朝代名),JSON 输出
- `/event/{id}` 事件页最小版本:SQLite 只读 `data/history.db.events` 表查 `id = ?`,返回 `name` / `year` / `category` 3 字段(join `dynasties` 表拿朝代名),JSON 输出
- 零样式 · Hello 级别 · 仅验证 web → SQLite 端到端联通

### 2. `frontend/App.jsx` —— React 最小入口占位
- 纯函数组件 `<App />` 返回 `<h1>历史顾问 Web</h1>` + 一段提示文字
- 实际渲染由后端 JSON 驱动,前端不直接查询 DB;此处仅占位验证 React 入口

### 3. `index.html` —— 根页面
- 静态 HTML,内联 CSS 仅 `<body>` 默认排版
- 标题"历史顾问 · Web 入口(W3 骨架 9/9)"
- 跳链 `backend/main.py` 启动后 `/person/1` / `/event/1` 验证
