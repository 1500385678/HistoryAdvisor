### 3.2 两流水线 schema(草案)

#### 流水线 1:`lookup` 人物速查

**触发命令**(飞书 Bot 私聊 / 群消息):
- `/历史 人物 秦始皇`
- `/history figure 嬴政`
- 文本兜底:含"谁" / "生平" / "简介" + 人物名

**输入**:`{ query: str, type: "figure" }`

**处理**:
1. `SELECT f.*, d.name AS dynasty_name FROM figures f LEFT JOIN dynasties d ON f.dynasty_id = d.id WHERE f.name LIKE ?`(`%query%` 模糊匹配)
2. 多结果按 `role` 优先级排序(帝王 > 名臣 > 思想家 > 名将)
3. 单结果 → 飞书消息卡(姓名 + 朝代 + 生卒年 + 角色 + 生平摘要 + 成就 + 评价)
4. 多结果 → 飞书消息卡(候选列表,点击展开详情)
5. 无结果 → 友好提示"未收录,试换关键词或朝代"

**输出**:飞书 `interactive` 消息卡 JSON

#### 流水线 2:`recap` 事件回顾

**触发命令**:
- `/历史 事件 赤壁之战`
- `/history event 安史之乱`
- 文本兜底:含"战役" / "变法" / "政变" / "事件" + 事件名

**输入**:`{ query: str, type: "event" }`

**处理**:
1. `SELECT e.*, d.name AS dynasty_name FROM events e LEFT JOIN dynasties d ON e.dynasty_id = d.id WHERE e.name LIKE ?`(`%query%` 模糊匹配)
2. 外键回查史料:`SELECT s.title, s.credibility FROM sources s WHERE s.dynasty_id = e.dynasty_id ORDER BY s.credibility DESC LIMIT 3`
3. 多结果按 `year` 升序(时间最近优先)
4. 单结果 → 飞书消息卡(事件名 + 朝代 + 年份 + 类别 + 地点 + 关键人物 + 摘要 + 影响 + 关联史料 3 部)
5. 多结果 → 飞书消息卡(候选列表,按时间排序)
6. 无结果 → 友好提示

**输出**:飞书 `interactive` 消息卡 JSON

### 3.3 DB 复用(基于现有 4 表)

- `figures`:32 行(帝王 18 / 名臣 6 / 思想家 7 / 名将 1)
- `events`:60 行(战争 22 / 制度 14 / 变法 6 / 政变 5 / 文化 5 / 起义 5 / 条约 3)
- `dynasties`:20 行(夏商周秦汉三国两晋南北朝隋唐五代宋元明清)
- `sources`:25 部核心史料(可信度 5★15 + 4★7 + 3★3)
